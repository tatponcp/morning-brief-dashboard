# คู่มือ IC Studio

หน้าที่ทีม IC ใช้ประกอบ Morning Brief ประจำวัน อยู่ที่ `/studio` (ต้องใส่รหัสผ่านของทีม)

## ขั้นตอนประจำวัน

1. **ตั้งวันที่** ที่หัวหน้าจอ ค่าเริ่มต้นคือวันนี้
2. กด **เริ่มวันใหม่** เพื่อล้างของเมื่อวาน — เลือกได้ว่าล้างเฉพาะรูป หรือล้างรูปพร้อมสัญญาณและข้อความ
   ชื่อหัวข้อ ชื่อ series และข้อมูลจากชีตจะยังอยู่ · กด `Ctrl + Z` ย้อนได้
3. ทำทีละข้อ 1 ถึง 6 แต่ละข้อมี 3 ขั้น
   - **ใส่ภาพ** — ลากไฟล์มาวาง กด `Ctrl + V` หรือคลิกเลือก เพิ่มจุดอธิบายบนภาพได้
   - **เลือกสัญญาณ** — ตอบ dropdown ตามสิ่งที่เห็นในภาพ พอครบระบบจะสรุป ให้คะแนน และร่างข้อความทันที
   - **ตรวจและแก้คำ** — แก้ได้ทุกช่อง (สรุปสั้น / แปลความ / Action วันนี้ / Insight)
4. ดูแถบขวาว่าลูกค้าจะเห็นอะไร แล้วกด **เผยแพร่ขึ้นเว็บ**
5. ถ้าต้องส่งภาพทางแชต กด **รูปส่งลูกค้า** เพื่อสร้างภาพสรุปของข้อนั้น

ร่างถูกบันทึกในเครื่องอัตโนมัติ ปิดหน้าไปแล้วกลับมาทำต่อได้

## สิ่งที่ควรรู้ในแต่ละข้อ

**ข้อ 1 · S50 + OI** — ช่อง Series อยู่ในขั้นเลือกสัญญาณ ช่วงย้ายสัญญาเพิ่ม series ที่สองได้
series แรกคือตัวหลักที่ใช้ตัดสินสถานการณ์ ถ้าใกล้หมดอายุ ระบบจะขึ้นแถบสีส้มเตือน
พร้อมปุ่มเพิ่มหรือสลับสัญญาถัดไป และจะถามเพิ่มเรื่อง OI รวมทุก series
ถ้าดูตัวเลขรวมไม่ได้ให้เลือก "ดูไม่ได้" ระบบจะอ่านจากแท่งราคาอย่างเดียว

**ข้อ 2 · สะสม Long / Short** — ข้อนี้มาจากชีต นำเข้า CSV ได้ที่ขั้นแรก
ระบบจะแนะนำการ์ดสถานการณ์ที่น่าจะใช่จากตัวเลขให้ก่อน

**ข้อ 3 ถึง 6** — ตอบ dropdown ตามภาพ แต่ละตัวเลือกมีคำอธิบายสั้นกำกับว่าหมายถึงอะไร

## คำของทีม

ถ้าแก้สำนวนแล้วชอบ กด **บันทึกเป็นคำของทีม** ครั้งต่อไปที่เลือกสถานการณ์เดิม
ระบบจะใช้คำชุดนั้นทันทีทั้งทีม กด **ใช้คำตั้งต้นของระบบ** เพื่อกลับไปใช้คำเดิมได้

บรรทัดที่ระบบเขียนจากข้อมูลของวันนั้น เช่น เรื่องช่วงย้ายสัญญา หรือ series ที่ไปคนละทาง
จะถูกเติมให้เสมอและไม่ถูกบันทึกปนกับคำของทีม

## ความแม่นย้อนหลัง

ปุ่ม **ความแม่นย้อนหลัง** ที่หัวหน้าจอเปิดหน้า `/studio/log` ซึ่งแสดง

- อัตราความแม่นของคะแนนภาพรวม และแบบที่ไม่นับข้อ 6
- ความแม่นแยกตามช่วงคะแนน และแยกตามข้อ
- ตารางรายวันพร้อมผลของ SET50 วันนั้น
- ปุ่มดาวน์โหลด CSV ไปวิเคราะห์ต่อ และปุ่มจดราคาปิดวันนี้เอง

ควรมีข้อมูลอย่างน้อย 20 วันทำการก่อนเริ่มเชื่อตัวเลข ระหว่างนั้นใช้ดูว่าข้อมูลเข้าครบทุกวันไหม

## คีย์ลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `Alt + 1` ถึง `Alt + 6` | สลับข้อ |
| `Ctrl + Z` / `Ctrl + Shift + Z` | ย้อนกลับ / ทำซ้ำ |
| `Ctrl + V` | วางภาพจากคลิปบอร์ดลงช่องภาพ |
| `Ctrl + K` | ค้นหา section (ฝั่งลูกค้า) |

## เมื่อมีปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| เข้า `/studio` แล้วเจอหน้า 503 | ยังไม่ได้ตั้ง `STUDIO_PASSWORD` บน Vercel |
| กดเผยแพร่แล้วขึ้นว่าติดต่อเซิร์ฟเวอร์ไม่ได้ | อินเทอร์เน็ตหลุด หรือ Supabase ล่ม ให้ลองใหม่ ร่างยังอยู่ |
| ขึ้นว่าภาพใหญ่เกินเก็บในเครื่อง | ร่างยังบันทึกข้อความให้ แต่ภาพจะไม่ถูกเก็บ ให้เผยแพร่เลยหรือย่อภาพก่อน |
| ลูกค้าเห็นหน้า "ยังไม่อัปเดตของวันนี้" | ฉบับล่าสุดยังเป็นของวันก่อน ให้ตรวจว่าเผยแพร่วันนี้แล้วหรือยัง |
