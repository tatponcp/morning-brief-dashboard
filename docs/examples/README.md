# ภาพตัวอย่าง

ใช้อ้างอิงว่าอะไรคือของเข้าและอะไรคือของออก

| โฟลเดอร์ | คืออะไร |
|---|---|
| `input/` | ภาพที่ IC แคปจากระบบเทรดมาใช้ทำงาน |
| `output/` | หน้าเว็บที่ลูกค้าได้อ่าน สร้างจากภาพและสัญญาณที่ IC เลือก |
| `ic-sheet-2026-09-14.csv` | ตัวอย่างชีตรายวันของทีม ใช้ทดลองปุ่มนำเข้าข้อมูลใน Studio |

เลขหน้าชื่อไฟล์ตรงกับหมายเลข section บนเว็บ ส่วน `0-summary.jpg` คือหน้าสรุปภาพรวม

ภาพในโฟลเดอร์นี้เป็นตัวอย่างสำหรับเอกสารเท่านั้น ไม่ได้ถูกใช้ตอนเว็บทำงานจริง
